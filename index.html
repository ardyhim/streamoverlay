Stream Overlay

Overlay Gallery

Kumpulan overlay HTML untuk OBS / browser source. Semua file statis, tanpa build step — tinggal buka atau copy ke dashboard Tako.

Params Builder

Rakit URL scene jadenbahtera/starting.html atau ending.html, lalu lihat hasilnya langsung di preview 1920×1080. Nama parameter mengikuti aturan baku di AGENTS.md.

Buka tab
jadenbahtera/starting.html

Preset

chatId = video ID saja · chatCrop hanya untuk iframe · chatBg=transparent hanya untuk mode box · minus dalam menit, boleh desimal · img harus mengizinkan CORS.
